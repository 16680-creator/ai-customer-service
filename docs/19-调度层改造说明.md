## 一、改造清单与验证结果

| # | 改造项 | 实现方式 | 验证结果 |
|---|---|---|---|
| 1 | chat 订单查询接真实 ai-cs-order | chat 引入 OpenFeign，`OrderFeignClient` 调 order 服务（注册中心负载均衡），mock 保留为降级 | ✅ 按订单号 / 按用户列表均返回真实 MySQL 订单数据 |
| 2 | chat 对话接入 RocketMQ 落库 | chat 引入 rocketmq-spring-boot-starter，对话消息投递 `chat-message-topic`，message 消费落库 `chat_db` | ✅ chat_message 已落库多条 user/assistant 消息 |

| 5 | 服务间调用规范化 | 引入 Spring Cloud OpenFeign（同步查询）+ 保持 RocketMQ 事件驱动（异步解耦） | ✅ Feign 调用 + MQ 事件均正常 |

## 二、各改造实现细节

### 2.1 chat 订单查询接真实 order（OpenFeign）

新增/修改：
- `ai-cs-chat/pom.xml`：spring-cloud-starter-openfeign + spring-cloud-starter-loadbalancer
- `ChatApplication`：`@EnableFeignClients`
- `ai-cs-chat/feign/OrderFeignClient`：`getOrderDetail` / `listOrders`（携带 X-User-Id）
- `ai-cs-chat/dto/OrderVO`：与 order 服务 OrderVO 字段一致的 DTO
- `ai-cs-chat/util/ChatUserContext`：ThreadLocal 保存当前用户（网关 X-User-Id 透传）
- `ChatController`：`/chat/send`、`/chat/rag` 接收 `X-User-Id` 并设置上下文
- `OrderQueryService`：`@Tool` 方法改为优先调 Feign，失败降级本地 mock
- `ai-cs-order`：新增 `GET /order/list`（按用户查列表）+ `OrderService.listOrders` + `toVO`

### 2.2 chat 对话接入 MQ 落库

新增/修改：
- `ai-cs-chat/pom.xml`：rocketmq-spring-boot-starter
- `ai-cs-chat/application.yml`：rocketmq name-server 配置
- `ai-cs-chat/mq/ChatMessageProducer`：投递 `chat-message-topic`（sessionKey/role/content）
- `ChatServiceImpl`：对话后投递 user + assistant 消息
- `ai-cs-message`：实体对齐 `chat_message` 表（sessionKey 字段、role 列），新增 `MybatisPlusConfig`（MetaObjectHandler 自动填充）
- 数据库：`chat_message` 表调整（id 自增、session_id 可空、新增 session_key/role、sender_type 默认值）

### 2.3 notify 联动

新增/修改：
- `ai-cs-notify/pom.xml`：rocketmq-spring-boot-starter
- `ai-cs-notify/consumer/OrderNotifyConsumer`：监听 `notify-topic` → WebSocket 推送
- `NotifyApplication`：scanBasePackages 补 com.aics.common
- `ai-cs-order/OrderServiceImpl.handlePayCallback`：支付成功后投递通知
- `ai-cs-order`：修复 items 为空时 `IN ()` SQL 报错的健壮性问题

### 2.4 定时任务

新增/修改：
- `OrderApplication`：`@EnableScheduling`
- `ai-cs-order/task/OrderTimeoutScheduler`：`@Scheduled(fixedDelay=300000)` 扫描超时未支付订单并取消（与 RocketMQ 延迟消息双保险）

### 2.5 服务间调用规范化

- 同步查询类调用 → OpenFeign（注册中心发现 + 负载均衡）
- 异步事件类调用 → RocketMQ（chat 消息、订单通知）
- 统一走网关（外部请求）+ 服务间经注册中心直连（Feign）/ MQ（事件）

3. **RocketMQ 为本地部署**：生产应使用集群部署；`deploy/nacos/configs/` 未入库（含敏感配置）。
4. **测试数据**：订单表新增 2 条测试订单（ORD202608070001/002），chat_message 有测试消息，可按需清理。
5. **定时任务固定 5 分钟**：如需精确分钟级调度，可替换为 XXL-Job（引入 xxl-job-core + 调度中心）。
