# 知识运营六菜单功能操作手册

> 适用菜单（首页「功能入口」红框标注）：**知识库管理、全文搜索、Prompt 管理、售后 Agent、知识图谱、RAG 评估**
> 配套测试数据：`deploy/testdata/` 目录（种子脚本 `seed-redbox-data.ps1`、演示 golden 集 `golden-set-demo.json`、可选 SQL `redbox-test-data.sql`）

## 1. 菜单总览

| 菜单 | 前端路由 | 页面组件 | 后端服务 | 核心接口（经网关 8080） |
| --- | --- | --- | --- | --- |
| 知识库管理 | `/knowledge` | `KnowledgeView.vue` | ai-cs-knowledge | `GET/POST/PUT/DELETE /api/knowledge…` |
| 全文搜索 | `/search` | `SearchView.vue` | ai-cs-search | `GET /api/search/{index}`、`POST/DELETE /api/search/index/{index}`、`POST /api/search/document/{index}` |
| Prompt 管理 | `/prompts` | `PromptView.vue` | ai-cs-chat | `GET /api/prompts`、`GET /api/prompts/{scenario}`、`POST /api/prompts/{scenario}/active` |
| 售后 Agent | `/agent` | `AgentView.vue` | ai-cs-chat | `GET /api/agent/health`、`POST /api/agent/stream/sse`（SSE 流式）、`POST /api/agent/confirm` |
| 知识图谱 | `/graph` | `GraphView.vue` | ai-cs-chat | `POST /api/rag/graph/triple`、`GET /api/rag/graph/query`、`GET /api/rag/graph/triples` |
| RAG 评估 | `/rag-eval` | `RagEvalView.vue` | ai-cs-chat | `POST /api/rag/eval/run` |

数据流关系（便于理解各菜单联动）：

```
知识库管理(写 MySQL kb_document) --RocketMQ 异步--> 向量化入 Chroma(knowledge 库)
全文搜索(索引文档) --> Chroma(knowledge/自定义库) + 同步写 ES
售后 Agent --> 意图识别(LLM) + 订单工具 + 规则检索(knowledge 库) + 待确认写操作
知识图谱 --> 三元组存储(默认进程内) + 多跳 BFS 检索
RAG 评估 --> 按 golden 集逐条检索(Chroma) + LLM-as-Judge 打分 + 门禁判定
```

## 3. 知识库管理（/knowledge）

### 3.1 功能说明

管理知识文档（MySQL `kb_document`）的增删改查与关键词检索；文档创建/更新/删除后经 RocketMQ 异步向量化到 Chroma 的 `knowledge` 库，供 RAG 对话与全文搜索使用。

### 3.2 操作步骤

| 操作 | 步骤 | 预期结果 |
| --- | --- | --- |
| 搜索 | 搜索框输入关键词（匹配**标题或标签**），点「搜索」；清空后可点 × 恢复全量 | 表格刷新为匹配结果 |
| 新增 | 点「新增文档」→ 填标题/分类/内容 → 保存 | 提示「保存成功」，列表出现新文档 |
| 查看 | 行内「眼睛」按钮 | 弹窗展示 ID/标题/分类/内容/创建时间 |
| 编辑 | 行内「编辑」按钮 → 修改 → 保存 | 保存成功，异步重新向量化 |
| 删除 | 行内「删除」→ 确认气泡「确认删除?」 | 删除成功，同时异步清除向量 |
| 翻页 | 底部分页组件 | 按创建时间倒序翻页 |

### 3.3 测试数据与验证

- 种子文档 2001~2006：搜索 `退款` 应命中「订单退款申请流程」「退货运费承担规则」；搜索 `保修` 命中「型号 ABC-123 保修期说明」。
- 新增一条标题含「蓝牙」的文档，保存后到「全文搜索」页用 `knowledge` 索引搜「蓝牙」可检索到（异步向量化约 1~3 秒）。
- 删除该文档后再搜，结果消失。

### 3.4 注意事项

- **状态列**：前端按 `status==1` 显示「启用」否则「禁用」；后端语义为 0-待处理 / 1-已索引 / 2-索引失败。页面创建的文档当前不回写状态，会显示「禁用」，**不影响实际向量化与检索**（已知展示差异）。
- **分类列**：后端实体暂无 category 字段，列表该列恒为空（已知展示差异）。
- 删除为逻辑删除（deleted=1），向量按 documentId 物理清除。

## 4. 全文搜索（/search）

### 4.1 功能说明

左侧为搜索区（索引名称 + 关键词），右侧为索引管理（创建/删除索引）与索引文档（JSON 写入）。底层为 **Chroma 语义检索**，索引文档时同步写一份到 ES。

### 4.2 操作步骤

1. **搜索**：索引名称填 `knowledge`（默认），输入关键词（如 `耳机保修`），回车或点「搜索」；结果卡片展示标题、内容、索引名与相关度。
2. **创建索引**：右侧「索引管理」填索引名（如 `faq-test`）→「创建索引」→ 提示成功（Chroma 模式无需真实建表，幂等）。
3. **索引文档**：「索引文档」区填索引名与 JSON 内容 →「索引文档」。JSON 必须合法，示例：

   ```json
   {"title":"客服工作时间","content":"人工客服工作时间为每日 9:00-21:00，节假日无休。","tags":"客服,人工"}
   ```

4. **删除索引**：填索引名 →「删除索引」→ 确认。会删除该库在 Chroma 的全部向量及 ES 文档。

### 4.3 测试数据与验证

- 搜 `knowledge` + `退款多久到账` → 命中种子文档/索引文档（相关度降序）。
- 搜 `faq-test` + `优惠券` → 命中脚本写入的 2 条 faq 文档。
- 索引一条新 JSON 到 `faq-test` 后立即可搜到。

### 4.4 注意事项

- ⚠️ **不要对 `knowledge` 索引执行「删除索引」**：会清空知识库自动向量化的全部向量（含种子文档），导致 RAG 评估/Agent 规则检索失效；删除演练请用 `faq-test`。
- 索引文档 JSON 不合法会提示「文档内容必须是合法 JSON」。
- ES 同步失败仅告警不影响 Chroma 搜索结果。

## 5. Prompt 管理（/prompts）

### 5.1 功能说明

配置化 Prompt 版本管理：左侧场景列表（来自 chat 服务 `application-prompt.yml`），右侧展示该场景全部版本、生效版本，支持**预览**与**热切换生效版本**（无需重启）。

内置 8 个场景：

| 场景 | 用途 |
| --- | --- |
| `default-system` | 默认系统提示词（AI 对话人设与工具规则） |
| `intent` | 售后 Agent 意图识别 |
| `rewrite` | RAG 查询改写 |
| `rag` | RAG 问答用户提示词 |
| `summary` | 对话历史摘要 |
| `judge` | RAG 评估 LLM-as-Judge 打分 |
| `chart` | 问数图表结论生成 |
| `vision` | 视觉/多模态指令 |

### 5.2 操作步骤

1. 左侧场景筛选框输入 `in` → 列表过滤出 `intent`。
2. 点击场景 → 右侧版本表展示版本（默认均 `v1`）、「生效中」标签、内容长度。
3. 点「预览」→ 弹窗查看完整 Prompt 文本（含 `{{var}}` 占位符）。
4. 点「刷新」重新拉取版本列表。
5. **设为生效**：当前生效版本按钮置灰；存在多版本时可将其他版本设为生效（热切换，立即影响后续对话/识别）。

### 5.3 测试与验证

- 预览 `intent` v1：内容应包含意图类型 `AFTER_SALE/PRODUCT_RECOMMEND/...`。
- 热切换演练：在 `application-prompt.yml` 为某场景（如 `rag`）新增 `v2` 并重启 chat 服务 → 页面出现 v2 → 点「设为生效」→ 提示「已将 rag 切换至 v2」→ 再切回 v1 验证回滚。

### 5.4 注意事项

- 页面为**只读 + 切换**，不支持在线编辑 Prompt 文本；版本内容修改走配置文件。
- 列表为空时检查 chat 服务配置 `aics.prompt.enabled=true`。

## 7. 知识图谱（/graph）

### 7.1 功能说明

三元组（主体-关系-客体）写入与多跳 BFS 检索。左卡片写三元组，右卡片按实体+深度（1~4）检索并以「主体 —关系→ 客体」链式展示，底部为三元组列表。

### 7.2 操作步骤

1. **写入**：知识库默认 `knowledge`；填主体/关系/客体（来源文档 ID 可选）→「写入图谱」→ 提示「三元组已写入」，列表自动刷新。
2. **多跳检索**：实体填 `退款政策`，深度 `2` →「检索」→ 展示两跳链路。
3. **列表刷新**：点「刷新」重新加载。

### 7.3 测试数据与验证

种子三元组（脚本已写入）：

| 主体 | 关系 | 客体 |
| --- | --- | --- |
| 退款政策 | 指向 | 订单详情页申请入口 |
| 订单详情页申请入口 | 适用于 | 已支付订单 |
| 耳机类商品 | 适用 | ASR-001 换货规则 |
| ASR-001 换货规则 | 期限 | 签收后 15 天内 |
| 退货运费 | 承担方 | 买家（非质量问题） |
| 退款 | 到账时效 | 1-3 个工作日 |

验证：实体 `退款政策` 深度 1 → 1 条；深度 2 → 2 条（含「适用于 已支付订单」）；实体 `耳机类商品` 深度 2 → 2 条。

### 7.4 注意事项

- 默认存储为**进程内**（`InMemoryGraphStore`），chat 服务重启后清空，需重跑脚本或重新写入；可通过配置切换 `Neo4jGraphStore` 持久化。
- 主体/关系/客体三项必填，缺一提示「请填写主体、关系、客体」。

## 8. RAG 评估（/rag-eval）

### 8.1 功能说明

基于固定 golden 集做回归评估：逐条用例检索（Chroma）→ 与期望文档比对算命中率 → LLM-as-Judge 打分 → 汇总门禁（低于阈值即 FAIL）。

### 8.2 参数说明

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 知识库 | `knowledge` | 请求级知识库，**覆盖**用例自带值 |
| 检索模式 | `VECTOR` | VECTOR / HYBRID / RERANK |
| golden 集路径 | `classpath:eval/golden-set.json` | 支持 `classpath:` 与 `file:` 前缀 |
| 命中率阈值 | 0.6 | 整体命中率低于该值门禁 FAIL |
| 评分阈值 | 3.5 | LLM 均分低于该值门禁 FAIL |

### 8.3 推荐演示步骤（使用演示 golden 集）

1. golden 集路径填（chat 服务所在机器的绝对路径）：

   ```
   file:D:/Projects/Persion/ai-customer-service/deploy/testdata/golden-set-demo.json
   ```

2. 知识库 `knowledge`、模式 `VECTOR`、命中率阈值 `0.6`、评分阈值 `1`。
3. 点「运行评估」→ 等待（6 条用例，含 LLM 打分，约数十秒）。
4. 查看结果：
   - **评估汇总**：用例总数 / 通过 / 失败 / 平均评分 / 命中率 / 门禁（PASS 绿 / FAIL 红）。
   - **逐条明细**：每用例的问题、命中（是/否）、评分、通过、回答、判定理由。

种子数据齐全时命中率应为 **1.0**（每条问题命中期望文档 2001~2006）。

### 8.4 内置 golden 集说明

- `classpath:eval/golden-set.json`：20 条用例，面向 `product-manual` 库，期望文档 ID 101~120。该 ID 体系用于**集成测试向向量库注入固定 ID** 的场景；演示环境经页面/脚本入库的向量 ID 为随机 UUID，命中率通常为 0，门禁 FAIL 属预期（可用于演示门禁拦截能力）。
- 当前实现 LLM Judge 以「检索上下文占位回答」打分，分数普遍偏低，演示 PASS 时评分阈值建议设 `1`（或 `0`）；**命中率是本次演示的主观察指标**。

### 8.5 注意事项

- `file:` 路径必须是 **chat 服务进程可访问**的绝对路径（本地开发即本机路径）。
- 评估失败红色告警常见原因：golden 集路径不存在、Chroma/LLM 服务不可用。

## 10. 常见问题（FAQ）

| 现象 | 原因与处理 |
| --- | --- |
| 页面跳回登录页 | Token 过期/未登录，重新登录（401 自动登出） |
| 全文搜索报「搜索查询失败」 | Chroma 或 search 服务未启动 |
| Agent 页顶部「服务异常」 | chat 服务未启动或 `/api/agent/health` 不通 |
| 知识库新增后搜不到向量结果 | 向量化为 MQ 异步（1~3 秒），稍等；检查 RocketMQ 与 Embedding 服务日志 |
| RAG 评估「golden 测试集加载失败」 | `file:` 路径错误或 chat 服务无权读取 |
| Prompt 页「暂无场景」 | chat 配置 `aics.prompt.enabled=false` 或服务未启动 |
| 图谱重启后列表为空 | 进程内存储特性，重跑种子脚本即可 |
| 误删 `knowledge` 索引 | 重跑种子脚本，并在知识库管理页对 2001~2006 逐条「编辑-保存」触发重新向量化 |
