## 三、维护规则

1. **编号不复用**：删除文档后，编号留空，不要拿新文档顶替旧编号（避免历史链接指向错误内容）。
2. **改完更新索引**：新增/删除/改号文档，必须同步更新本文第二节与 [14-配置说明](14-项目配置文件和目录说明.md) 的目录表。
3. **过期就打标，不要删**：历史快照保留原结论 + 顶部状态标记 + 新增"现状复核"章节，比直接删除更有价值（能讲演进过程）。
4. **写清时点**："当前""最近"这类词必须配日期，否则三个月后就是错误信息。
