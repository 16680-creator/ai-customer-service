## 一、答题四层模板

```text
第 1 层 定性：一句话说清它是什么/解决什么问题
第 2 层 机制：关键实现（数据结构/流程/参数）
第 3 层 项目：我们项目里怎么用的（给具体场景）
第 4 层 边界：什么情况下不适用/踩过什么坑
```

> 只答第 1 层 = 背过；能答到第 3 层 = 做过；第 4 层 = 有判断。

## 二、Java 基础（10 题）

| 题 | 答法骨架 | 常见追问/坑 |
|---|---|---|
| HashMap 原理 | 数组+链表+红黑树；默认 16、负载因子 0.75；链表长度 8 树化、6 退化；扩容 2 倍，元素分高低位 | 为什么是 2 的幂？为什么阈值 8？（泊松分布） |
| ConcurrentHashMap 1.8 | CAS + synchronized 锁桶头；`size` 用 baseCount + CounterCell | 为什么不用分段锁了？ |
| ArrayList vs LinkedList | 数组随机访问 O(1)，链表头尾 O(1) 但寻址慢、缓存不友好；实际多用 ArrayList | 什么时候真用 LinkedList？（队列/频繁头插） |
| String 为什么不可变 | `final` 数组 + 不提供修改方法；常量池复用、线程安全、hash 缓存 | 字符串拼接为什么用 StringBuilder？ |
| equals 与 hashCode | 契约：equals 相等则 hashCode 必须相等；重写要成对 | 只重写 equals 会怎样？（HashMap 找不到） |
| 泛型擦除 | 编译期检查、运行期擦除；桥方法；不能 `new T[]` | 为什么 `List<String>` 不能赋给 `List<Object>`？ |
| 反射与动态代理 | 运行时获取类信息；JDK 代理基于接口、CGLIB 基于继承 | CGLIB 为什么不能代理 final 类？ |
| 异常体系 | `Throwable` → `Error`/`Exception`；checked 必须处理 | `finally` 里有 return 会怎样？ |
| Java 17 新特性 | record、sealed、switch 模式匹配、文本块 | 生产用了吗？（诚实答） |
| 序列化 | `Serializable` 有安全风险（反序列化漏洞） | 为什么推荐 JSON/Protobuf？ |

## 三、JVM（8 题）

| 题 | 答法骨架 | 常见追问/坑 |
|---|---|---|
| 内存区域 | 堆、虚拟机栈、本地方法栈、方法区（元空间）、程序计数器、直接内存 | 哪些线程共享？ |
| 对象创建 | 类加载检查 → 分配（指针碰撞/空闲列表）→ 零值 → 对象头 → 构造 | TLAB 是什么？ |
| GC 算法 | 标记清除（碎片）、复制（新生代）、标记整理（老年代）、分代收集 | 为什么分代？ |
| G1 | Region 划分、可预测停顿、SATB、Mixed GC | G1 适合多大堆？和 CMS 区别？ |
| ZGC | 染色指针、并发标记/转移、停顿 < 1ms | 生产用了吗？（JDK 17+ 可用） |
| 类加载 | 加载→验证→准备→解析→初始化；双亲委派 | 什么时候破坏双亲委派？（SPI/Tomcat） |
| 调优参数 | `-Xms/-Xmx` 相等、`-XX:MaxMetaspaceSize`、GC 日志、`HeapDumpOnOutOfMemoryError` | 为什么不建议 `-Xmn` 乱设？ |
| OOM 类型 | heap/metaspace/direct/GC overhead/unable to create thread | 分别怎么查？ |

## 四、并发（10 题）

| 题 | 答法骨架 | 常见追问/坑 |
|---|---|---|
| 线程状态 | NEW/RUNNABLE/BLOCKED/WAITING/TIMED_WAITING/TERMINATED | BLOCKED 和 WAITING 区别？ |
| synchronized 原理 | 对象头 Mark Word + monitor；锁升级：偏向→轻量→重量 | 锁能降级吗？ |
| volatile | 可见性（内存屏障）+ 有序性；不保证原子性 | `i++` 为什么不行？ |
| AQS | `state` + CLH 双向队列 + CAS；独占/共享 | ReentrantLock 公平锁怎么实现？ |
| ReentrantLock vs synchronized | 可中断、可超时、可公平、条件变量；synchronized 简单 | 什么时候选哪个？ |
| 线程池 7 参数 | core/max/keepAlive/unit/queue/threadFactory/handler；执行顺序：核心→队列→最大→拒绝 | 队列满了才扩到 max，为什么？ |
| 线程数怎么定 | CPU 密集 ≈ 核数+1；IO 密集 ≈ 核数 × (1+等待/计算) | 有公式就够吗？（要压测） |
| ThreadLocal | 线程内副本；`ThreadLocalMap` key 是弱引用 | 为什么会内存泄漏？ |
| CAS 与 ABA | 比较并交换；ABA 用版本号/AtomicStampedReference | 自旋开销怎么办？ |
| 死锁 | 互斥/占有等待/不可剥夺/循环等待；`jstack` 看 deadlock | 怎么预防？（顺序/超时） |

## 五、Spring（8 题）

| 题 | 答法骨架 | 常见追问/坑 |
|---|---|---|
| IoC 容器启动 | `refresh()`：准备→BeanFactory→后置处理器→注册 BeanDefinition→实例化→完成 | BeanFactory 和 FactoryBean？ |
| Bean 生命周期 | 实例化→属性注入→Aware→BPP.before→init→BPP.after（代理诞生）→使用→销毁 | 循环依赖在哪一步解决？ |

| 事务传播 | REQUIRED/REQUIRES_NEW/NESTED/SUPPORTS/NOT_SUPPORTED/MANDATORY/NEVER | REQUIRES_NEW 什么时候用？ |
| 自动装配 | `@EnableAutoConfiguration` → `AutoConfiguration.imports` → 条件注解 | 怎么排除某个自动配置？ |
| MVC 请求流程 | Filter → DispatcherServlet → HandlerMapping → 拦截器 → 参数绑定 → 返回处理 | 拦截器和 Filter 区别？ |
| 事务失效场景 | 自调用、非 public、异常被吞、传播设置错、多线程、类未被代理 | 怎么验证？（集成测试） |

## 六、MySQL（10 题）

| 题 | 答法骨架 | 常见追问/坑 |
|---|---|---|
| 索引结构 | InnoDB B+ 树；聚簇索引叶子存行，二级索引存主键（回表） | 为什么不用 B 树/哈希？ |
| 最左前缀 | 联合索引按定义顺序匹配；范围查询后面的列失效 | `like '%x'` 为什么失效？ |

| redo/undo/binlog | redo 崩溃恢复、undo 回滚+MVCC、binlog 复制/审计 | 两阶段提交为什么需要？ |
| 慢查询优化 | `EXPLAIN` → 索引 → 改写 → 分页优化 → 拆表 | 深分页怎么优化？ |
| 分库分表 | 垂直/水平；分片键选择；跨库 join/分页/事务 | 分片键选错会怎样？ |
| 主从延迟 | `Seconds_Behind_Master`；大事务/无主键/并行复制 | 读写分离怎么保证读到最新？ |

## 十三、答不上来时

```text
1. 不硬编："这块我没深入，我按理解说，您看对不对。"
2. 给相邻知识："类似的 X 我了解，区别在于……"
3. 给学习路径："如果要做，我会先看 A 再验证 B。"
4. 收回到会的地方："我对 Y 比较熟，可以展开。"
```

> 面试官能接受"不会"，不能接受"装会"。
