## 三、四个"模板级"写法

### 3.1 LRU（HashMap + 双向链表）

```java
class LRUCache {
    class Node {
        int key, value;
        Node prev, next;
        Node(int k, int v) { key = k; value = v; }
    }
    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0);

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
            return;
        }
        if (map.size() == capacity) {
            Node last = tail.prev;
            remove(last);
            map.remove(last.key);
        }
        Node newNode = new Node(key, value);
        map.put(key, newNode);
        addFirst(newNode);
    }

    private void moveToHead(Node node) { remove(node); addFirst(node); }
    private void addFirst(Node node) {
        node.next = head.next; node.prev = head;
        head.next.prev = node; head.next = node;
    }
    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}
```

**追问**：线程安全怎么做？→ 加锁（`synchronized`/`ReentrantLock`），或直接用 `ConcurrentHashMap + 并发链表`；生产用 Caffeine。

### 3.2 生产者-消费者（BlockingQueue）

```java
public class ProducerConsumer {
    private final BlockingQueue<Integer> queue = new ArrayBlockingQueue<>(10);

    public void produce() throws InterruptedException {
        for (int i = 0; ; i++) queue.put(i);   // 满了阻塞
    }

    public void consume() throws InterruptedException {
        while (true) {
            Integer v = queue.take();          // 空了阻塞
            // 处理 v
        }
    }
}
```

**追问**：`put/take` 和 `offer/poll` 区别？→ 前者阻塞，后者立即返回/超时。

### 3.3 两个线程交替打印

```java
public class AlternatePrint {
    private final Object lock = new Object();
    private int count = 1;

    public void printOdd() {
        synchronized (lock) {
            while (count <= 100) {
                if (count % 2 == 1) {
                    System.out.println(Thread.currentThread().getName() + ": " + count++);
                    lock.notifyAll();
                } else {
                    try { lock.wait(); } catch (InterruptedException e) { Thread.currentThread().interrupt(); return; }
                }
            }
        }
    }
    // printEven 同理，判断 count % 2 == 0
}
```

**考点**：`while` 而不是 `if`（防虚假唤醒）、`notifyAll` 而不是 `notify`。

### 3.4 令牌桶（简化）

```java
public class TokenBucket {
    private final long capacity;
    private final long ratePerSecond;
    private double tokens;
    private long lastRefillNanos = System.nanoTime();

    public TokenBucket(long capacity, long ratePerSecond) {
        this.capacity = capacity;
        this.ratePerSecond = ratePerSecond;
        this.tokens = capacity;
    }

    public synchronized boolean tryAcquire() {
        refill();
        if (tokens >= 1) { tokens -= 1; return true; }
        return false;
    }

    private void refill() {
        long now = System.nanoTime();
        double add = (now - lastRefillNanos) / 1_000_000_000.0 * ratePerSecond;
        tokens = Math.min(capacity, tokens + add);
        lastRefillNanos = now;
    }
}
```

**追问**：分布式怎么做？→ Redis + Lua，key 存 tokens 和 lastRefillTime，脚本内原子更新。

## 四、Java 手撕的 10 个坑

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | `Integer` 缓存 -128~127，`==` 比较出错 | 用 `equals` 或 `intValue()` |
| 2 | 重写 `equals` 不重写 `hashCode` | 两者一起重写 |
| 3 | `Arrays.asList` 返回定长列表 | 要可变用 `new ArrayList<>(...)` |
| 4 | `subList` 是视图，原列表改动会失效 | 需要独立列表就复制 |
| 5 | 循环里字符串 `+=` | 用 `StringBuilder` |
| 6 | 自动拆箱 NPE（`Integer` 为 null） | 先判空 |
| 7 | `ConcurrentModificationException` | 用 `Iterator.remove` 或 `removeIf` |
| 8 | `volatile` 不保证原子性 | 计数用 `AtomicInteger` |
| 9 | `ThreadLocal` 不 remove 导致泄漏 | `finally` 里 `remove()` |
| 10 | `HashMap` 并发扩容死循环（JDK 8 前） | 并发用 `ConcurrentHashMap` |

## 六、白板/共享屏幕注意事项

1. **先写函数签名和注释**，再写实现（面试官知道你思路清晰）。
2. **边写边说**："这里我用 HashMap 存节点，保证 O(1) 查找。"
3. **写完主动测**：空输入、单元素、重复、边界。
4. **主动说复杂度**：时间/空间，以及能否优化。
5. **卡住时**：说出卡在哪 + 给暴力解 + 再优化（不要沉默）。
