# 07 - 面试流程与话术

> **目标**：技术之外的那 30%——自我介绍、项目讲述、反问、HR 面、谈薪、压力面。
> **前提**：[01 岗位地图](01-岗位地图与JD拆解.md)、[02 简历](02-简历与项目包装.md)、[06 刁钻追问](06-项目刁钻追问50题.md)。
> **纪律**：所有话术都是**骨架**，必须替换成你自己的事实；不编经历、不贬低前公司、不过度自谦。

---

## 一、面试全流程地图

```text
投递/内推 → 简历筛 → 笔试/测评 → 一面（基础+项目）
→ 二面（项目深挖+场景）→ 三面（设计+软素质）→ HR 面 → offer/谈薪 → 背调
```

每一轮的目标不同：

| 轮次 | 对方想确认 | 你的策略 |
|---|---|---|
| 一面 | 基础是否扎实、项目是否真做过 | 八股答三层，项目讲主链路 |
| 二面 | 深度、排查能力、设计能力 | 讲取舍、讲踩坑、讲数据 |
| 三面 | 视野、稳定性、潜力 | 讲方法论、讲规划 |
| HR 面 | 动机、稳定性、薪资匹配 | 真诚、口径一致、不卑不亢 |

---

## 二、面试前 24 小时

### 2.1 公司与岗位调研

- 公司主业、技术栈（看招聘 JD、技术博客、开源仓库）；
- 岗位所在团队做什么（To B/To C、交易/平台/数据）；
- 近期新闻（融资、裁员、新业务）——面试时能接话。

### 2.2 准备三个清单

| 清单 | 内容 |
|---|---|
| **必答题** | 自我介绍、项目介绍、离职原因、职业规划、优缺点 |
| **反问** | 5 个问题（见第六节） |
| **底线** | 薪资底线、通勤底线、加班底线 |

### 2.3 远程面试检查

- 网络（有线优先）、摄像头、麦克风、背景；
- 共享屏幕只开需要的窗口（关微信/邮件）；
- 准备纸笔/白板工具；
- 提前 10 分钟进入。

## 三、自我介绍（1 分钟）

### 3.1 结构（四段）

```text
1. 我是谁：姓名 + 年限 + 方向（10 秒）
2. 我做过什么：1~2 个项目，各一句话（25 秒）
3. 我最擅长什么：3 个关键词 + 一个证据（20 秒）
4. 我为什么来：与岗位的匹配点（5 秒）
```

### 3.2 模板（有经验版）

```text
面试官好，我是 XXX，做 Java 后端 X 年。
最近两年主要在做 XX 系统，一个是交易链路（下单/支付/售后），
一个是 AI 客服（RAG + Agent）。
我比较有把握的是三块：分布式一致性、Redis/MySQL 调优、以及把 AI 能力接进业务。
我看这个岗位偏 XX 方向，和我做的比较匹配，所以来试试。
```

### 3.3 模板（应届/转行版）

```text
面试官好，我是 XXX，XX 学校 XX 专业，主要方向是 Java 后端。
我系统学过 Java/Spring/MySQL/Redis，也自己做过一个 12 模块的微服务项目，
从网关限流、订单状态机到 RAG 检索都跑通过。
我知道自己缺真实生产经验，所以最近在补生产排障和稳定性这块。
```

### 3.4 常见错误

| 错误 | 纠正 |
|---|---|
| 背简历 3 分钟 | 控制在 60~90 秒 |
| 只报技术名词 | 每个名词带一个场景 |
| 过度自谦（"我都很浅"） | 说"我比较有把握的是 X" |
| 不提岗位匹配 | 最后一句回到 JD |

## 四、项目讲述

### 4.1 3 分钟版（一面）

```text
背景（30s）：为什么做这个系统，解决什么问题
挑战（30s）：2~3 个难点（一致性/性能/安全）
方案（90s）：每个难点一句"怎么解 + 为什么"
结果（30s）：数据或验证方式
```

### 4.2 10 分钟版（二面）

```text
架构（2min）：一张图，讲清模块与主链路
一条主链路（3min）：下单→支付→回调→对账
一个难点（3min）：锁/事务/幂等/对账，讲三层
一个取舍（1min）：为什么最终一致而不是全链路 Seata
一个反思（1min）：如果重做会怎么改
```

### 4.3 引导追问的技巧

- 主动埋钩子："这里有个坑，我们后来发现……"（面试官大概率会追问）；
- 留一个"我特别熟"的点，等他问；
- 不要一次讲完，留 20% 等他问。

## 五、技术面话术

### 5.1 不会时

```text
"这块我没深入做过，我按理解说一下思路，您看对不对。"
"类似的是 XX，区别在于……"
"如果要做，我会先查 A，再验证 B。"
```

### 5.2 被质疑时

```text
"您说的这个风险确实存在，我们当时的考虑是 XX，代价是 YY。"
（先承认，再给背景，最后给代价——不要硬杠）
```

### 5.3 被追问到底时

```text
"再往下就是源码/协议层了，我读到 XX 这一层，再深我没跟过。"
（诚实划边界，比瞎编强）
```

### 5.4 冷场时

```text
"我先说一下整体思路，您看要不要展开某一层？"
（主动给结构，别沉默）
```

## 六、反问环节（最后 5 分钟）

### 6.1 推荐问的 5 个

| 问题 | 目的 |
|---|---|
| 团队目前的技术栈和下一步演进方向？ | 判断匹配与成长 |
| 这个岗位最看重的能力是什么？ | 判断匹配度，也为后续准备 |
| 团队的分工和 Code Review 流程？ | 看工程规范 |
| 新人上手一般多久？有没有导师？ | 看培养机制 |
| 团队最近遇到的最大技术挑战？ | 看技术密度，也给自己埋话题 |

### 6.2 不要问

- 加班多不多（换问"团队发布节奏"）；
- 工资多少（HR 面谈）；
- 公司会不会倒、领导好不好；
- 一上来就问年假/调休。

## 七、HR 面

### 7.1 高频问题与答法

| 问题 | 答法边界 |
|---|---|
| 为什么离职？ | 说"发展/方向"，不说前公司坏话；裁员就说裁员（正常） |
| 职业规划？ | 3 年做深一个方向（与岗位一致），别说"想转管理/创业" |
| 优缺点？ | 优点带证据；缺点说"真实但不致命"的（如"有时太关注细节"）+ 改进 |
| 能接受加班吗？ | "项目需要时可以，长期靠流程提效"——不硬刚也不跪 |
| 为什么选我们？ | 业务 + 技术 + 个人匹配三点，别说"离家近" |
| 手上有其他 offer 吗？ | 有就说有（不必说名字），没有就说"在看" |
| 期望薪资？ | 给区间（见第八节），先问"岗位预算范围" |

### 7.2 稳定性信号

- 频繁跳槽（<1 年）要能解释；
- 空窗期要能说清在做什么（学习/项目/家庭）；
- 口径一致：简历、面试、背调不能矛盾。

---

## 八、谈薪

### 8.1 先搞清总包结构

```text
总包 = 月薪 × 月数 + 年终奖 + 补贴 + 股票/期权 + 签字费
```

要问清：

- 月薪是固定还是含绩效？
- 几薪？去年实际发了几薪？
- 社保公积金基数（按全额还是最低）？
- 试用期工资比例、试用期时长；
- 期权行权价、归属周期、回购条款。

### 8.2 报价策略

| 步骤 | 做法 |
|---|---|
| 1 | 先问预算："这个岗位的薪资范围大概是多少？" |
| 2 | 给区间不给点："我期望 XX~YY"（区间下限是你的底线） |
| 3 | 用总包谈，不只看月薪 |
| 4 | 有竞品 offer 可提（不说具体公司），但别编 |
| 5 | 涨幅合理：跳槽 20%~30% 常见，超过 50% 要有理由 |

### 8.3 话术

```text
"我目前的 package 是 XX，期望有合理涨幅。
我更看重岗位的成长和团队，薪资上希望能在 XX 以上。
如果预算有差距，我们可以看看签字费/职级/调薪周期有没有空间。"
```

> 不要先自降："我都可以"——会被压价。

## 九、压力面

| 场景 | 应对 |
|---|---|
| 被否定（"你这个方案不行"） | 先问"您觉得主要风险在哪"，再解释取舍，不硬杠 |
| 被沉默（故意不说话） | 主动补一句"我是不是哪里没讲清楚？" |
| 被质疑学历/空窗 | 承认事实 + 说清你在做什么 + 转到能力证据 |
| 被问隐私（婚育） | 礼貌拒答："这个和岗位关系不大，我更想聊聊技术。" |
| 被压薪 | "低于我的底线我可能无法接受，但我很愿意再聊聊岗位。" |

## 十、面试后

### 10.1 感谢信（可选，24 小时内）

```text
您好，感谢今天的时间。关于 XX 问题，我回来又想了想，
补充一个思路：…… 如果有机会加入，我希望先在 XX 上贡献力量。
```

### 10.2 复盘（当天）

| 项 | 记录 |
|---|---|
| 被问到的题 | 哪些答得好/卡住 |
| 卡住的原因 | 不会 / 会但没讲清 / 紧张 |
| 面试官关注点 | 他在哪些地方追问 |
| 下次改进 | 具体到"补哪个知识点/练哪个话术" |

> 复盘表模板见 [08 面试复盘与投递管理](08-面试复盘与投递管理.md)（待写）。

## 十一、远程面试注意

- 提前测试设备，准备备用热点；
- 看着摄像头说话，不是看屏幕；
- 共享屏幕前关掉无关窗口；
- 手边放简历、项目一页纸、纸笔；
- 网络卡顿时主动说"我这边网络有点问题，我重复一下"。

---

## 十二、话术禁忌

| 禁忌 | 原因 |
|---|---|
| 贬低前公司/同事 | 面试官会想"你以后也会这么说我们" |
| 过度自谦 | 显得不自信 |
| 编造经历/数据 | 追问两句就穿，且可能进黑名单 |
| 说"我什么都能做" | 没有重点 |
| 只问薪资福利 | 显得只看钱 |
| 面试中接电话/回消息 | 不专业 |

---

## 十三、模拟面试脚本（30 分钟）

```text
0-3min   自我介绍（录音回听）
3-8min   项目 3 分钟版 + 追问 2 个
8-18min  技术题 5 道（从 19/03 抽）
18-25min 设计题 1 道（从 19/04 抽）
25-28min 反问 2 个
28-30min 复盘：哪里卡住、下次怎么改
```

**找人扮演面试官**，或用手机录像；回看时注意：

- 有没有"然后/就是"超过 5 次；
- 有没有眼神飘、摸头发；
- 回答有没有结构（第一/第二/第三）。
