# 08 - 面试复盘与投递管理

> **目标**：让每一次面试都留下资产，而不是"面完就忘"。
> **核心公式**：`进步 = 面试次数 × 复盘质量`。只面不复盘，等于重复练习同一个错误。
> **前提**：[07 面试流程与话术](07-面试流程与话术.md)。

---

## 一、为什么必须复盘

| 不复盘 | 复盘 |
|---|---|
| 同一个问题被问倒 5 次 | 第 2 次就能答三层 |
| 不知道卡在哪一轮 | 清楚是"技术不够"还是"表达不行" |
| 投递凭感觉 | 用数据调整策略（渠道/公司/岗位） |
| 越面越焦虑 | 看到自己在变好 |

---

## 二、单场复盘表（面试当天填）

```markdown
## 基本信息
- 公司 / 岗位 / 轮次 / 日期 / 面试官角色
- 渠道：内推 / 官网 / BOSS / 猎头

## 题目记录
| # | 问题 | 我的回答 | 自评（好/中/差） | 卡点 |
|---|------|---------|----------------|------|
| 1 |      |         |                |      |

## 卡点归类（选一个主因）
- [ ] 不会（知识盲区）
- [ ] 会但没讲清（表达问题）
- [ ] 紧张/心态
- [ ] 项目不匹配（岗位错配）
- [ ] 薪资/地点等非技术原因

## 改进项（具体到动作）
- 补：____（知识点/文档）
- 练：____（话术/手撕）
- 改：____（简历/项目描述）

## 面试官关注点
- 他在哪些地方追问？追问了几层？
- 他反复问的是哪个方向？（说明岗位真正看重）
```

## 三、失败归因分类

| 类型 | 表现 | 对策 |
|---|---|---|
| **知识盲区** | 问题完全不会 | 回对应模块补，列入下周计划 |
| **表达问题** | 会但讲乱了 | 用"四层模板"重写答案，录音练习 |
| **深度不够** | 第一层就停了 | 补原理 + 项目锚点 |
| **岗位错配** | 方向/技术栈不符 | 调整投递方向，别硬投 |
| **薪资/地点** | 谈崩 | 提前确认底线与预算 |
| **竞争** | 都答得不错但没 offer | 正常，继续投；可能是 HC/排序 |

> 最怕的是"不知道输在哪"——所以复盘表必须填"卡点"。

## 四、投递管理表

```markdown
| 公司 | 岗位 | 渠道 | 投递日 | 状态 | 一面 | 二面 | 三面 | HR | 结果 | 备注 |
|------|------|------|--------|------|------|------|------|----|------|------|
| A    | Java | 内推 | 10-20  | 一面 | 10-22|      |      |    |      | 问了 JVM |
```

**状态**：已投 / 已读 / 约面 / 一面 / 二面 / 三面 / HR / offer / 拒 / 无回应。

**每周统计**：

| 指标 | 计算 | 健康值参考 |
|---|---|---|
| 简历→一面转化率 | 一面数 / 投递数 | 10%~20% |
| 一面→二面转化率 | 二面数 / 一面数 | 30%~50% |
| 二面→offer 转化率 | offer 数 / 二面数 | 20%~40% |
| 平均响应天数 | — | 3~7 天 |

> 转化率低在哪一环，就补哪一环：简历→一面低 = 简历问题；一面→二面低 = 技术/表达；二面→offer 低 = 深度/匹配。

---

## 五、每周复盘节奏（30 分钟）

```text
1. 更新投递表（5 分钟）
2. 汇总本周面试卡点，按类型统计（10 分钟）
3. 选 Top2 卡点，排进下周学习计划（10 分钟）
4. 调整下周投递名单（5 分钟）
```

## 六、如何利用拒信/反馈

- 大部分公司不给反馈，**别等**；
- 能拿到反馈的（内推人/HR），重点问："哪方面差距最大？"
- 把反馈原话记下来，别急着辩解；
- 如果 3 家以上反馈同一个问题，那就是真问题。

## 七、心态管理

| 现象 | 真相 |
|---|---|
| 投了 50 家没回音 | 正常，简历/渠道/时机都可能有问题 |
| 一面就挂 | 可能只是岗位不匹配，不是能力否定 |
| 面到 HR 被拒 | 薪资/稳定性/竞争，不一定是技术 |
| 越面越差 | 疲劳战；停下来复盘 1~2 天再投 |

**建议**：每周最多 3~5 场面试，留出复盘和补短板的时间。

---

## 八、常见误区

| 误区 | 纠正 |
|---|---|
| 面完就忘 | 当天填复盘表（趁热） |
| 只记题目不记卡点 | 卡点才是改进方向 |
| 广撒网不记录 | 用表管理，否则重复投/漏跟进 |
| 被拒就否定自己 | 归因到具体环节，别归因到"我不行" |
| 拿到 offer 就停止 | 复盘"为什么这家要我"，复制成功因素 |
