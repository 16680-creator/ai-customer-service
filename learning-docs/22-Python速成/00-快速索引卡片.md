## ⚠️ 高频坑（先看这5个）

| 坑 | 现象 | 解法 | 详细位置 |
|----|------|------|---------|
| **默认参数陷阱** | `def f(x=[])` 所有调用共享同一个列表 | 用 `None` + 函数内创建 | [04篇 §1.2](04-函数与作用域.md) |
| **浅拷贝** | 修改嵌套列表时原数据也变了 | `copy.deepcopy()` | [03篇 §6](03-数据类型与容器.md) |
| **GIL 限制** | 多线程 CPU 密集任务不加速 | 用进程池 | [08篇 §1](08-并发模型.md) |
| **async 中阻塞调用** | `time.sleep()` 让整个事件循环卡住 | 改用 `await asyncio.sleep()` | [08篇 §5.2](08-并发模型.md) |
| **整数除法** | `7 / 2` 返回 `3.5` 不是 `3` | 整除用 `//` | [02篇 §2](02-语法速通-Java对照.md) |
