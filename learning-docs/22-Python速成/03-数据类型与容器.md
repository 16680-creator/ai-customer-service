# 03 · 数据类型与容器

> 这一篇解决一个具体问题：**Java 的 `List/Map/Set` 那套经验，怎么迁移到 Python 的 `list/dict/set/tuple` 上。**
> 重点不是"有哪些方法"，而是三类容易出错的地方：**可变性、拷贝语义、哈希契约**。

---

## 一、四种容器的定位

| Python | Java 最近对应 | 有序 | 可变 | 可哈希（能当 dict 键） | 典型用途 |
|---|---|---|---|---|---|
| `list` | `ArrayList` | ✅ | ✅ | ❌ | 绝大多数有序数据 |
| `tuple` | 无（类似 `record` 的不可变部分） | ✅ | ❌ | ✅（元素都不可变时） | 固定结构、函数返回多值、dict 键 |
| `dict` | `LinkedHashMap` | ✅（3.7+ 保证插入序） | ✅ | ❌ | 键值映射 |
| `set` | `HashSet` | ❌ | ✅ | ❌ | 去重、成员判断 |
| `frozenset` | `Collections.unmodifiableSet` | ❌ | ❌ | ✅ | 需要当键的集合 |

```python
lst  = [1, 2, 3]
tup  = (1, 2, 3)
dct  = {"a": 1, "b": 2}
st   = {1, 2, 3}
fs   = frozenset({1, 2})
```

> **注意**：`{}` 是空字典，不是空集合！空集合必须写 `set()`。这是新手高频错误。

```python
type({})        # <class 'dict'>
type(set())     # <class 'set'>
```

## 二、list：你的主力容器

### 创建与初始化

```python
[]                          # 空
[1, 2, 3]
[0] * 5                     # [0,0,0,0,0]      Java 的 Arrays.fill
list(range(5))              # [0,1,2,3,4]
list("abc")                 # ['a','b','c']    字符串可迭代
[x * 2 for x in range(3)]   # [0,2,4]

# 二维列表：⚠️ 经典陷阱
bad = [[0] * 3] * 3         # ❌ 三行是同一个列表对象！
bad[0][0] = 9
print(bad)                  # [[9,0,0],[9,0,0],[9,0,0]]

good = [[0] * 3 for _ in range(3)]   # ✅ 每个内层独立
good[0][0] = 9
print(good)                 # [[9,0,0],[0,0,0],[0,0,0]]
```

### 常用方法（对照 Java）

| 操作 | Java | Python | 复杂度 |
|---|---|---|---|
| 追加 | `add(e)` | `append(e)` | 均摊 O(1) |
| 批量追加 | `addAll(c)` | `extend(c)` | O(k) |
| 插入 | `add(i, e)` | `insert(i, e)` | O(n) |
| 按索引取 | `get(i)` | `lst[i]` | O(1) |
| 按索引删 | `remove(i)` | `pop(i)` | O(n) |
| 删末尾 | — | `pop()` | O(1) |
| 按值删 | `remove(obj)` | `remove(v)`（不存在抛 ValueError） | O(n) |
| 查找下标 | `indexOf(o)` | `index(v)` | O(n) |
| 包含 | `contains(o)` | `v in lst` | O(n) |
| 长度 | `size()` | `len(lst)` | O(1) |
| 清空 | `clear()` | `clear()` | O(n) |
| 排序 | `Collections.sort` | `sort()` / `sorted()` | O(n log n) |
| 反转 | `Collections.reverse` | `reverse()` / `reversed()` | O(n) |
| 拷贝 | `new ArrayList<>(l)` | `l.copy()` / `l[:]` | O(n) |

```python
fruits = ["apple", "banana"]
fruits.append("cherry")         # ['apple','banana','cherry']
fruits.extend(["date", "elder"])# 批量
fruits.insert(0, "avocado")     # 头插
last = fruits.pop()             # 弹末尾
first = fruits.pop(0)           # 弹头部（O(n)）

fruits.remove("banana")         # 按值删
idx = fruits.index("cherry")    # 找下标

# 切片赋值（Java 没有，非常强）
nums = [0, 1, 2, 3, 4, 5]
nums[1:3] = [10, 20, 30]        # [0,10,20,30,3,4,5]  长度可变
del nums[0]                     # 删指定下标
nums.clear()
```

### 排序的两种姿势

```python
# 原地排序（= Collections.sort）
nums = [3, 1, 2]
nums.sort()
print(nums)              # [1,2,3]

# 返回新列表（= Stream.sorted().collect()）
nums = [3, 1, 2]
new = sorted(nums)
print(nums, new)         # [3,1,2] [1,2,3]

# 自定义比较：key 函数（比 Java Comparator 简洁）
orders = [
    {"no": "A", "amount": 300},
    {"no": "B", "amount": 100},
    {"no": "C", "amount": 200},
]
orders.sort(key=lambda o: o["amount"])              # 按金额升序
orders.sort(key=lambda o: o["amount"], reverse=True)

# 多字段排序：返回元组即可
orders.sort(key=lambda o: (o["amount"], o["no"]))

# 稳定排序 → Python 的 sort 是稳定的，可以分步排（先排次要字段，再排主要字段）
```

```java
// Java 等价
orders.sort(Comparator.comparingInt(o -> o.getAmount()).reversed());
```

### 切片（**Python 独有的高频能力**）

```python
a = [0, 1, 2, 3, 4, 5]

a[1:4]      # [1,2,3]       左闭右开
a[:3]       # [0,1,2]
a[3:]       # [3,4,5]
a[-2:]      # [4,5]         最后两个
a[:-2]      # [0,1,2,3]
a[::2]      # [0,2,4]       步长 2
a[::-1]     # [5,4,3,2,1,0] 反转
a[4:1:-1]   # [4,3,2]       反向切片

# 切片返回新列表（浅拷贝）
b = a[:]
b[0] = 99
print(a[0])     # 0，不受影响

# 字符串、元组同样支持切片
"hello"[1:3]    # 'el'
```

## 三、dict：用得比 list 还多

### 创建

```python
{}                              # 空
{"a": 1, "b": 2}
dict(a=1, b=2)                  # 关键字构造
dict([("a", 1), ("b", 2)])      # 从键值对列表
dict(zip(["a","b"], [1,2]))     # 两个列表合并 —— 高频
{k: v for k, v in pairs}        # 推导式
dict.fromkeys(["a","b"], 0)     # {'a':0,'b':0}
```

### 取值：**永远优先用 `get`**

```python
d = {"a": 1}

d["a"]              # 1
d["missing"]        # ❌ KeyError（不像 Java Map 返回 null）

d.get("missing")            # None
d.get("missing", 0)         # 0         ← 等价 Optional.orElse

# 陷阱：or 做默认值时，0/""/False 也会被替换
d = {"count": 0}
d.get("count") or 100       # ❌ 得到 100
d.get("count", 100)         # ✅ 得到 0
```

### 增删改

```python
d = {}
d["a"] = 1
d["a"] = 2                  # 覆盖，不报错
d.setdefault("b", [])       # 不存在才插入
d.setdefault("b", []).append(1)     # 经典用法：分组
d.update({"c": 3, "d": 4})  # putAll
del d["a"]                  # 删除，不存在抛 KeyError
d.pop("a", None)            # 安全删除
d.clear()

merged = d1 | d2            # 3.9+ 合并，右边覆盖左边
d1 |= d2                    # 原地合并
```

### 遍历

```python
for k in d:                     # 键
for v in d.values():            # 值
for k, v in d.items():          # 键值对 ← 最常用

# 遍历时不能改大小（会 RuntimeError，等价 Java 的 ConcurrentModificationException）
for k in list(d.keys()):        # ✅ 先复制键列表
    del d[k]
```

### 分组（替代 `Collectors.groupingBy`）

```python
from collections import defaultdict

orders = [
    {"type": "A", "amount": 100},
    {"type": "B", "amount": 200},
    {"type": "A", "amount": 300},
]

grouped = defaultdict(list)
for o in orders:
    grouped[o["type"]].append(o)

print(dict(grouped))
# {'A': [{...100}, {...300}], 'B': [{...200}]}

# 一次遍历完成"求和分组"
totals = defaultdict(float)
for o in orders:
    totals[o["type"]] += o["amount"]
print(dict(totals))      # {'A': 400.0, 'B': 200.0}
```

`defaultdict` 的价值：**不用先判断 key 是否存在**，省掉一层分支。这比 Java 里 `computeIfAbsent` 还顺手。

```java
// Java 等价
Map<String, List<Order>> grouped = orders.stream()
    .collect(Collectors.groupingBy(Order::getType));
```

## 四、set

```python
s = {1, 2, 3}           # 字面量
s = set([1, 2, 3])      # 从可迭代
s = set()               # 空集合（不能用 {}）

s.add(4)
s.discard(4)            # 不存在不报错
s.remove(4)             # 不存在抛 KeyError
4 in s                  # O(1)  ← 比 list 快得多

a = {1, 2, 3}
b = {2, 3, 4}
a | b       # 并集 {1,2,3,4}
a & b       # 交集 {2,3}
a - b       # 差集 {1}
a ^ b       # 对称差 {1,4}
a <= b      # 子集
a |= b      # 原地并

frozenset({1, 2})       # 不可变，可当 dict 键
```

**性能提醒**：`x in list` 是 O(n)，`x in set` 是 O(1)。要去重的场景，先把大数据转 `set` 再判断，否则数据量一大就是灾难。

```python
# 列表去重且保留顺序（高频需求）
seen = set()
result = []
for x in [3, 1, 3, 2, 1]:
    if x not in seen:
        seen.add(x)
        result.append(x)
print(result)       # [3,1,2]

# 或者用 dict.fromkeys（3.7+ 保证顺序）
list(dict.fromkeys([3, 1, 3, 2, 1]))    # [3,1,2]
```

## 六、推导式：把 Java Stream 甩在后面的地方

```python
# 映射
[x * 2 for x in range(5)]                     # [0,2,4,6,8]
# Java: IntStream.range(0,5).map(x -> x*2).boxed().toList()

# 过滤
[x for x in range(10) if x % 2 == 0]          # [0,2,4,6,8]

# 映射 + 过滤
[x * 2 for x in range(10) if x % 2 == 0]

# 嵌套（等价 flatMap）
[x for row in [[1,2],[3,4]] for x in row]     # [1,2,3,4]
# Java: rows.stream().flatMap(List::stream).toList()

# 字典推导
{k: v for k, v in [("a", 1), ("b", 2)]}
{v: k for k, v in d.items()}                   # 反转键值
{k: len(k) for k in ["a", "bb"]}               # {'a':1, 'bb':2}

# 集合推导
{x % 3 for x in range(10)}                     # {0,1,2}

# 条件表达式（if-else 都写）
[x if x > 0 else 0 for x in [-1, 0, 1]]        # [0,0,1]

# 生成器表达式：惰性，省内存（见 04 篇）
total = sum(x * x for x in range(1_000_000))   # 不建中间列表
```

### 可读性边界

推导式超过一层 for + 一个 if，就该改写成普通循环。**不要为了"一行"牺牲可读性**——这是 Python 社区明确反对的（PEP 8）。

```python
# ❌ 过度嵌套
result = [f(x, y) for x in xs if p(x) for y in ys if q(y) and r(x, y)]

# ✅ 拆开
result = []
for x in xs:
    if not p(x):
        continue
    for y in ys:
        if q(y) and r(x, y):
            result.append(f(x, y))
```

## 七、可变性与拷贝（**Java 程序员最容易翻车的地方**）

Java 里"对象赋值是引用复制"你很清楚；Python 一样，但更隐蔽——因为**连字符串/元组/列表都用同样的 `=`**。

### 变量名是标签，不是盒子

```python
a = [1, 2, 3]
b = a               # b 和 a 指向同一个列表
b.append(4)
print(a)            # [1,2,3,4]  ← a 也变了

# 浅拷贝
c = a.copy()
c = a[:]
c = list(a)
c.append(99)
print(a)            # [1,2,3,4]  不受影响
```

### 浅拷贝的边界

```python
import copy

nested = [[1, 2], [3, 4]]

shallow = nested.copy()         # 只复制外层
shallow[0][0] = 99
print(nested)                   # [[99,2],[3,4]]  ❌ 内层被改了

deep = copy.deepcopy(nested)    # 完全独立
deep[0][0] = 77
print(nested)                   # [[99,2],[3,4]]  ✅ 不受影响
```

**规则**：容器里装容器 → 需要 `deepcopy`。容器里只装不可变值（数字/字符串/元组）→ 浅拷贝够用。

### 函数参数是"传对象引用"

```python
def add_bad(item, lst=[]):      # ❌ 默认值只创建一次
    lst.append(item)
    return lst

print(add_bad(1))    # [1]
print(add_bad(2))    # [1, 2]   ← 不是 [2]！

def add_good(item, lst=None):   # ✅ 标准写法
    if lst is None:
        lst = []
    lst.append(item)
    return lst

# 传入可变对象会被改
def mutate(lst):
    lst.append(99)

data = [1]
mutate(data)
print(data)   # [1, 99]  ← Java 也是这样，但 Java 里你会警惕，Python 里容易忘
```

## 八、哈希契约：`__eq__` 与 `__hash__`

把对象放进 `set` 或做 `dict` 键时，Python 要求**可哈希**。这和 Java 的 `equals/hashCode` 契约完全一致，但默认行为不同：

```python
class Order:
    def __init__(self, no):
        self.no = no

a = Order("A")
b = Order("A")
print(a == b)               # False  ← 默认按身份比较（等价 Java 的 ==）
print(len({a, b}))          # 2      ← 两个都在

# 自定义类要实现值相等
class Order2:
    def __init__(self, no):
        self.no = no
    def __eq__(self, other):
        if not isinstance(other, Order2):
            return NotImplemented
        return self.no == other.no
    def __hash__(self):
        return hash(self.no)

print(Order2("A") == Order2("A"))       # True
print(len({Order2("A"), Order2("A")}))  # 1

# 最省事：用 dataclass（自动生成 __eq__，frozen=True 还会生成 __hash__）
from dataclasses import dataclass

@dataclass(frozen=True)
class Order3:
    no: str

print(Order3("A") == Order3("A"))       # True
print(len({Order3("A"), Order3("A")}))  # 1
```

> **坑**：定义了 `__eq__` 却没定义 `__hash__`，该类就变成不可哈希（Python 自动把 `__hash__` 置 None），扔进 set 会 `TypeError: unhashable type`。这比 Java 更"严格"——Java 是静默用身份哈希，导致 HashSet 行为诡异。

## 九、性能与复杂度速查

| 操作 | list | dict/set | 说明 |
|---|---|---|---|
| 按索引访问 | O(1) | — | |
| 按值查找 `in` | O(n) | O(1) | **能用 set 就别用 list 判断存在** |
| 头部插入 | O(n) | — | 需要队列用 `collections.deque` |
| 尾部追加 | O(1) 均摊 | O(1) 均摊 | |
| 删除任意位置 | O(n) | O(1) | |
| 排序 | O(n log n) | — | |

```python
# 队列：别用 list.pop(0)
from collections import deque

q = deque([1, 2, 3])
q.append(4)         # 右入
q.appendleft(0)     # 左入
q.pop()             # 右出
q.popleft()         # 左出 O(1)   ← list.pop(0) 是 O(n)
```

```python
# 一个可以直接抄走的分组统计模板（业务代码高频）
from collections import defaultdict

def summarize(records: list[dict]) -> dict[str, dict]:
    acc = defaultdict(lambda: {"count": 0, "total": 0.0})
    for r in records:
        slot = acc[r["category"]]
        slot["count"] += 1
        slot["total"] += r["amount"]
    return dict(acc)
```
