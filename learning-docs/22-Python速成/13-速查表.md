    @functools.wraps(fn)

## 六、并发

```python
# IO 密集 → asyncio
import asyncio

async def f():
    await asyncio.sleep(1)

async def main():
    await asyncio.gather(f(), f())              # 并发
    async with asyncio.TaskGroup() as tg:       # 3.11+
        tg.create_task(f())
    await asyncio.wait_for(f(), timeout=1)
    await asyncio.to_thread(blocking_fn, arg)   # 阻塞调用隔离 ← 必须

asyncio.run(main())

# 限流
sem = asyncio.Semaphore(10)
async with sem: ...

# 线程池（IO 密集 + 同步库）
from concurrent.futures import ThreadPoolExecutor, as_completed
with ThreadPoolExecutor(max_workers=10) as pool:
    list(pool.map(fn, xs))
    for fut in as_completed(fs): fut.result()

# 进程池（CPU 密集）
from concurrent.futures import ProcessPoolExecutor
if __name__ == "__main__":
    with ProcessPoolExecutor() as pool:
        pool.map(fn, xs)       # fn 必须是模块级函数

# 队列
import queue
q = queue.Queue(maxsize=100)
q.put(x); q.get(); q.task_done()
```

**决策**：IO 密集 → asyncio / 线程池；CPU 密集 → 进程池。

## 九、必背 10 条

```text
1.  缩进即语法，禁止 Tab/空格混用
2.  `x is None` 判空，`==` 比值
3.  默认参数别用可变对象：def f(x=None)
4.  dict 取值用 .get()，别用 []
5.  所有 open 都写 encoding="utf-8"
6.  async def 里禁止同步阻塞，用 await asyncio.to_thread()
7.  CPU 密集用进程池，IO 密集用协程/线程
8.  json.dumps 加 ensure_ascii=False
9.  包内代码用 python -m 运行
10. 金额用 Decimal，不用 float
```
