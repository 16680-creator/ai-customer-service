### 题目 1：偶数的平方

给定 `[1..10]`，返回所有偶数的平方组成的列表。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 1 思路——先造数据，再用推导式一步完成"过滤 + 映射" ----
nums = list(range(1, 11))
# ↑ range(1,11) 是惰性序列 1..10，list() 物化成列表；≈ IntStream.rangeClosed(1,10).boxed().toList()
result = [x * x for x in nums if x % 2 == 0]
# ↑ 列表推导式：对每个 x 先判断偶数（x % 2 == 0），再平方；等价 Java stream filter+map
print(result)        # [4, 16, 36, 64, 100]
# ↑ 输出验证：偶数为 2,4,6,8,10，平方后即 4,16,36,64,100
```

Java 对照：`IntStream.rangeClosed(1,10).filter(x->x%2==0).map(x->x*x).boxed().toList()`

统计字符串每个字符出现次数。

```python
from collections import Counter
# ↑ Counter 是 dict 的子类，专门做计数；≈ stream().collect(groupingBy(x->x, counting()))

text = "hello world"
print(dict(Counter(text)))
# ↑ Counter(text) 统计每个字符出现次数，dict() 转回普通字典便于打印；
#   结果里 l 出现 3 次、o 出现 2 次，空格也算一个字符
# {'h':1,'e':1,'l':3,'o':2,' ':1,'w':1,'r':1,'d':1}

# 不用 Counter 的写法
counts = {}
# ↑ 空字典当累加器；Java 要 new HashMap<Character,Integer>()
for ch in text:
    # ↑ 直接迭代字符串拿到每个字符（Java 要 toCharArray()）
    counts[ch] = counts.get(ch, 0) + 1
    # ↑ get(ch,0) 键不存在时给 0，再 +1 写回；避免 KeyError（≈ getOrDefault）
```

**考点**：`Counter` 是标准库里最省事的计数工具。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 3 思路——zip 把两个序列"拉链"成键值对，dict() 直接收成字典 ----
keys = ["a", "b", "c"]
# ↑ 键列表
vals = [1, 2, 3]
# ↑ 值列表，与 keys 一一对应
print(dict(zip(keys, vals)))       # {'a': 1, 'b': 2, 'c': 3}

print(dict(zip(["a","b"], [1,2,3])))   # {'a': 1, 'b': 2}
# ↑ 只有 2 个键，第 3 个值被丢弃（不会报错）；这是常见静默 bug，长度不等时要先校验
```

### 题目 4：任意参数的 max

接收任意数量参数，返回最大值；无参数返回 `None`。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 4 思路——*args 收集任意个参数，空元组是假值所以返回 None ----
def max_of(*nums):
    # ↑ *nums 把调用时所有位置参数收成一个元组；Java 写作 int... nums
    return max(nums) if nums else None
    # ↑ 元组非空才调用 max；空元组在布尔上下文为 False（Java 要显式判断 length == 0）

print(max_of())              # None
# ↑ 不传参 ⇒ nums == () ⇒ 走 else 分支
print(max_of(3, 1, 4, 1, 5)) # 5
# ↑ 传 5 个参数 ⇒ nums == (3,1,4,1,5)，max 返回 5
```

**考点**：`*nums` 收集成元组；空元组是 falsy。

### 题目 5：安全取深层值

`get_nested(d, "a.b.c", default=0)`，路径不存在时返回 default。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 5 思路——按 "." 拆路径逐层下钻，任一层不存在就返回默认值 ----
def get_nested(data, path, default=None):
    # ↑ data 是嵌套字典，path 形如 "a.b.c"，default 是不存在时的兜底值
    cur = data
    # ↑ 游标指针，从根开始；Java 里会用 Map<String,Object> cur = data
    for key in path.split("."):
        # ↑ split(".") 把 "a.b.c" 拆成 ["a","b","c"]，逐级遍历
        if not isinstance(cur, dict) or key not in cur:
            # ↑ 当前层不是字典（走不下去了）或键不存在 ⇒ 直接返回默认值；≈ instanceof + containsKey
            return default
        cur = cur[key]
        # ↑ 下钻一层；≈ cur = (Map) cur.get(key)
    return cur
    # ↑ 路径全部走通，返回最深层的值

d = {"a": {"b": {"c": 42}}}
# ↑ 三层嵌套字典
print(get_nested(d, "a.b.c"))          # 42
# ↑ 正常路径，返回 42
print(get_nested(d, "a.x.c", 0))       # 0
# ↑ "x" 不存在，提前返回默认值 0
print(get_nested(d, "a.b.c.d", -1))    # -1
# ↑ 走到 42 后还想下钻，42 不是 dict，返回 -1
```

**加分项**：处理 list 索引。

</details>

### 题目 6：FizzBuzz

1..30，3 的倍数打印 Fizz，5 的倍数打印 Buzz，15 的倍数打印 FizzBuzz。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 6 思路——先判断 15 的倍数，再判 3/5；顺序错了会得不到 FizzBuzz ----
for i in range(1, 31):
    # ↑ range(1,31) 生成 1..30（右开）；≈ for(int i=1;i<=30;i++)
    if i % 15 == 0:
        # ↑ 必须最先判 15（即 3 和 5 的公倍数），否则会被下面的 3 分支抢先
        print("FizzBuzz")
    elif i % 3 == 0:
        # ↑ 3 的倍数；elif 相当于 else if
        print("Fizz")
    elif i % 5 == 0:
        # ↑ 5 的倍数
        print("Buzz")
    else:
        # ↑ 都不是，原样打印数字
        print(i)
```

### 题目 8：判断回文

忽略大小写和非字母数字。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 8 思路——先清洗（转小写 + 去掉非字母数字），再与反转串比较 ----
import re
# ↑ 正则库；≈ java.util.regex

def is_palindrome(s: str) -> bool:
    # ↑ 类型注解：入参 str、返回 bool；≈ boolean isPalindrome(String s)
    cleaned = re.sub(r"[^a-z0-9]", "", s.lower())
    # ↑ s.lower() 统一小写；re.sub 把"非 a-z0-9"的字符全部替换为空串；
    #   r"..." 是原始字符串，避免反斜杠转义；≈ replaceAll("[^a-z0-9]", "")
    return cleaned == cleaned[::-1]
    # ↑ 清洗后的串与它的反转比较；切片 [::-1] 一步反转，回文则相等

print(is_palindrome("A man, a plan, a canal: Panama"))   # True
# ↑ 忽略大小写、空格、标点后是回文
print(is_palindrome("hello"))                            # False
# ↑ 反转是 "olleh"，不相等
```

</details>

### 题目 10：列表去重保序

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 10 思路——利用 dict 键唯一且保留插入序，一行去重且保序 ----
nums = [3, 1, 3, 2, 1, 4]
# ↑ 含重复的列表
print(list(dict.fromkeys(nums)))    # [3, 1, 2, 4]
# ↑ dict.fromkeys 用元素做键（自动去重，值全为 None），3.7+ 保持首次出现顺序；
#   再 list() 取出键；≈ LinkedHashSet 的语义

# 或者
seen, out = set(), []
# ↑ 双变量同时赋值：seen 是已见集合，out 是结果列表
for x in nums:
    # ↑ 顺序遍历，保证"保序"
    if x not in seen:
        # ↑ 集合查询 O(1)；≈ HashSet.contains
        seen.add(x)
        out.append(x)
        # ↑ 首次出现才记录并加入结果
```

### 题目 12：计算文件行数（大文件友好）

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 12 思路——文件对象本身就是迭代器，逐行计数不占内存 ----
def count_lines(path: str) -> int:
    # ↑ 入参路径、返回行数；≈ int countLines(String path)
    with open(path, encoding="utf-8") as f:
        # ↑ with 保证关闭文件；encoding 显式指定，避免平台默认编码差异
        return sum(1 for _ in f)      # 逐行迭代，内存恒定
        # ↑ 生成器表达式每读一行产出 1，sum 累加；_ 表示"不关心这一行的内容"
        #   等效 Java：Files.lines(path).count()（注意 Files.lines 也要 try-with-resources）

# 不要这样（会把整个文件读进内存）
# return len(Path(path).read_text(encoding="utf-8").splitlines())
# ↑ read_text 一次性读入全文，再 splitlines 生成列表；大文件会 OOM，只是反例
```

### 题目 13：按多个字段排序

订单列表按 `amount` 降序、`order_no` 升序排列。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 13 思路——多字段排序的两种做法；核心是"稳定排序"和"降序取负" ----
from operator import itemgetter
# ↑ itemgetter("k") 返回一个"取字典 k 字段"的函数，比 lambda 略快

orders = [
    # ↑ 待排序订单；金额相同（B、A 都是 100）时靠第二关键字决定顺序
    {"order_no": "B", "amount": 100},
    {"order_no": "A", "amount": 100},
    {"order_no": "C", "amount": 300},
]

# 方式一：两次稳定排序（先次要字段，再主要字段）
orders.sort(key=itemgetter("order_no"))
# ↑ 先按单号升序；sort 是稳定排序，相等元素的相对顺序保持不变
orders.sort(key=itemgetter("amount"), reverse=True)
# ↑ 再按金额降序；因为稳定，金额相同的 A/B 会保留上一步的单号升序

# 方式二：一次复合 key（注意降序要取负）
orders.sort(key=lambda o: (-o["amount"], o["order_no"]))
# ↑ key 返回元组，元组按字典序比较：先比 -amount（金额越大越靠前），再比 order_no 升序
#   ≈ Comparator.comparing(Order::getAmount).reversed().thenComparing(Order::getNo)
print([o["order_no"] for o in orders])     # ['C', 'A', 'B']
# ↑ 列表中取字段组成结果；C(300) 第一，A/B(100) 按单号升序
```

**考点**：Python 的 `sort` 是稳定排序，可以分步排；也可以用负号实现"某字段降序"。

</details>

### 题目 14：分组统计

`[{"cat":"A","amt":10},{"cat":"B","amt":20},{"cat":"A","amt":5}]` → `{"A": {"count":2,"total":15}, "B": {"count":1,"total":20}}`

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 14 思路——defaultdict 免判空分组，每条记录累加 count 和 total ----
from collections import defaultdict
# ↑ 带默认值的字典：键不存在时自动调用工厂函数生成初始值

records = [
    # ↑ 待聚合的原始记录
    {"cat": "A", "amt": 10},
    {"cat": "B", "amt": 20},
    {"cat": "A", "amt": 5},
]

acc = defaultdict(lambda: {"count": 0, "total": 0})
# ↑ 工厂必须写成 lambda（每次返回新字典）；若写成 defaultdict({"count":0}) 所有键会共享同一个 dict
for r in records:
    # ↑ 逐条处理
    slot = acc[r["cat"]]
    # ↑ 访问即创建：首次遇到 "A"/"B" 时自动得到 {"count":0,"total":0}
    slot["count"] += 1
    # ↑ 计数 +1
    slot["total"] += r["amt"]
    # ↑ 金额累加

print(dict(acc))
# ↑ 转普通 dict 打印；defaultdict 在输出上和 dict 一样
# {'A': {'count': 2, 'total': 15}, 'B': {'count': 1, 'total': 20}}
```

`defaultdict(lambda: ...)` 的关键：**factory 必须是可调用对象**，不能直接写 `defaultdict({...})`（那样所有键共享同一个 dict）。

</details>

### 题目 15：写一个带参数的装饰器

`@retry(times=3, exceptions=(ValueError,))`：失败重试，最后仍失败则抛出。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 15 思路——三层嵌套实现"带参装饰器"：参数 → 装饰器 → 包装函数 ----
import functools
# ↑ 用 wraps 保留被装饰函数的元信息
import time
# ↑ 用 sleep 做重试间隔

def retry(times=3, delay=0.0, exceptions=(Exception,)):
    # 第 1 层：接收装饰器参数；times 次数、delay 间隔秒、exceptions 只重试哪些异常
    def decorator(fn):
        # 第 2 层：接收被装饰函数
        @functools.wraps(fn)
        # ↑ 保留 fn 的 __name__/__doc__，否则日志里都叫 wrapper
        def wrapper(*args, **kwargs):
            # 第 3 层：真正被调用的包装函数，透传任意参数
            last = None
            # ↑ 保存最后一次异常，全部失败时抛出
            for attempt in range(1, times + 1):
                # ↑ 尝试 1..times
                try:
                    return fn(*args, **kwargs)
                    # ↑ 成功立刻返回，不再重试
                except exceptions as e:
                    # ↑ 只捕获指定异常；其他异常直接向上冒泡
                    last = e
                    if attempt < times and delay:
                        # ↑ 最后一次不等待；delay=0 时也不 sleep
                        time.sleep(delay)
            raise last
            # ↑ 循环结束仍失败 ⇒ 抛出最后一次异常；≈ 把原异常重新抛出
        return wrapper
    return decorator


calls = {"n": 0}
# ↑ 用可变 dict 记录调用次数（闭包里改 dict 不需要 nonlocal）

@retry(times=3, exceptions=(ValueError,))
# ↑ 等价 flaky = retry(times=3, exceptions=(...))(flaky)
def flaky():
    calls["n"] += 1
    # ↑ 每次调用自增
    if calls["n"] < 3:
        # ↑ 前两次故意失败，第三次成功
        raise ValueError(f"第 {calls['n']} 次失败")
        # ↑ f-string 插入当前次数
    return "成功"

print(flaky(), calls["n"])     # 成功 3
# ↑ 前两次抛异常被装饰器捕获重试，第三次返回 "成功"，总调用次数 3
```

</details>

### 题目 16：批量分批生成器

`batch([1..5], 2)` → `[[1,2],[3,4],[5]]`

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 16 思路——边遍历边攒缓冲区，满 size 就 yield 一批，最后补余数 ----
from collections.abc import Iterable, Iterator
# ↑ Iterable=可迭代（能 for），Iterator=迭代器（能 next）；仅作类型注解

def batch(items: Iterable, size: int) -> Iterator[list]:
    # ↑ 输入任意可迭代对象，返回一个"批次迭代器"（惰性）
    buf = []
    # ↑ 当前批次缓冲区
    for it in items:
        # ↑ 逐个消费源数据，不一次性载入
        buf.append(it)
        # ↑ 放入当前批
        if len(buf) == size:
            # ↑ 攒满一批
            yield buf
            # ↑ 产出后函数暂停；注意这里交出去的是同一个 list 对象
            buf = []
            # ↑ 重新开一个空列表，避免下一轮修改已产出的批
    if buf:
        # ↑ 循环结束仍有剩余（不是 size 的整数倍）
        yield buf
        # ↑ 补最后一批

print(list(batch(range(1, 6), 2)))      # [[1, 2], [3, 4], [5]]
# ↑ 1..5 每 2 个一批；list() 把生成器全部取出，验证结果为三批
```

**加分**：用 `itertools.islice` 实现任意迭代器版本。

</details>

### 题目 17：用 dataclass 实现 Money

支持 `+`、`==`、排序、打印，币种不同时抛异常。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 17 思路——dataclass 承载数据 + 魔术方法定义运算/比较/打印 ----
from dataclasses import dataclass
# ↑ 自动生成 __init__ / __repr__ / __eq__
from functools import total_ordering
# ↑ 只要实现 __eq__ 和 __lt__，其余比较符（<=、>、>=）自动补齐

@total_ordering
# ↑ 装饰器作用于类，补全比较方法
@dataclass(frozen=True)
# ↑ frozen=True ⇒ 不可变且自动生成 __hash__，可放进 set；≈ record
class Money:
    # ↑ 值对象：金额 + 币种
    amount: float
    # ↑ 金额
    currency: str = "CNY"
    # ↑ 币种，默认人民币

    def _check(self, other):
        # ↑ 内部校验方法（下划线前缀约定为私有）
        if not isinstance(other, Money):
            # ↑ 类型不对，直接抛错；≈ instanceof
            raise TypeError("只能和 Money 相加")
        if self.currency != other.currency:
            # ↑ 不同币种不能直接运算
            raise ValueError(f"币种不一致：{self.currency} vs {other.currency}")

    def __add__(self, other):
        # ↑ 定义 + 运算符；≈ 重载 operator+
        self._check(other)
        # ↑ 先校验类型和币种
        return Money(self.amount + other.amount, self.currency)
        # ↑ 返回新对象（frozen 不允许原地改）

    def __lt__(self, other):
        # ↑ 定义 < 运算符；total_ordering 依赖它推导其余比较
        self._check(other)
        # ↑ 同样要求同币种才能比较
        return self.amount < other.amount
        # ↑ 按金额比较

    def __str__(self):
        # ↑ print 时调用；≈ toString()
        return f"{self.amount:.2f} {self.currency}"
        # ↑ 保留两位小数并带币种


a, b = Money(10), Money(5.5)
# ↑ 依次构造两个对象（元组解包赋值）
print(a + b)                       # 15.50 CNY
# ↑ 触发 __add__，再触发 __str__ 输出
print(sorted([Money(3), Money(1)])) # [Money(amount=1,...), Money(amount=3,...)]
# ↑ sorted 用 __lt__ 排序；打印用 dataclass 自动生成的 __repr__
try:
    # ↑ 演示跨币种异常
    Money(1) + Money(1, "USD")
    # ↑ 触发 __add__ → _check → 抛 ValueError
except ValueError as e:
    # ↑ 捕获并打印异常消息
    print("捕获：", e)
```

**注意**：`@dataclass(frozen=True)` 会自动生成 `__hash__`，所以可放 set。`@total_ordering` 只需实现 `__eq__` + `__lt__` 就能得到全部比较符。

### 题目 20：按字符数切分文本（不切断单词）

`chunk("hello world foo", 12)` → 每段不超过 12 字符，且在空格处断。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 20 思路——贪心装箱：能塞进当前段就塞，塞不下就收尾另起一段 ----
def chunk(text: str, size: int) -> list[str]:
    # ↑ 按单词边界切分，保证每段长度 <= size
    words = text.split()
    # ↑ 按空白拆成单词列表，天然去掉多余空格
    out, cur = [], ""
    # ↑ out 存已完成段落，cur 存当前正在攒的段落
    for w in words:
        # ↑ 逐词尝试装入
        candidate = f"{cur} {w}".strip()
        # ↑ 候选段 = 当前段 + 空格 + 新词；strip 去掉开头多余空格
        if len(candidate) <= size:
            # ↑ 装得下就接受
            cur = candidate
        else:
            # ↑ 装不下 ⇒ 当前段定稿，新词另起一段
            if cur:
                # ↑ 当前段非空才收（处理第一个词就超长的情况）
                out.append(cur)
            cur = w
            # ↑ 新段从当前词开始
    if cur:
        # ↑ 循环结束，最后一段也要收
        out.append(cur)
    return out

print(chunk("hello world foo bar", 12))
# ↑ 验证切分结果
# ['hello world', 'foo bar']
```

### 题目 22：CSS 风格的参数合并

实现 `merge(*dicts, deep=True)`，后者覆盖前者，deep 时递归合并。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 22 思路——递归合并多个字典；deep=True 时同键且都是 dict 就继续递归 ----
def merge(*dicts, deep=True):
    # ↑ *dicts 收集任意多个字典；deep 是"仅关键字"参数（必须写 deep=...）
    out = {}
    # ↑ 结果字典，从空开始逐层合并
    for d in dicts:
        # ↑ 按传入顺序处理，后者覆盖前者
        for k, v in d.items():
            # ↑ 遍历当前字典的键值对
            if deep and isinstance(v, dict) and isinstance(out.get(k), dict):
                # ↑ 深度合并条件：v 是字典，且 out 里同键也已是字典
                out[k] = merge(out[k], v, deep=True)
                # ↑ 递归合并子字典；≈ 递归版 putAll
            else:
                # ↑ 浅合并：直接覆盖（包括 v 是标量或 out 里同键不是字典）
                out[k] = v
    return out
    # ↑ 返回合并结果（注意可变值仍是浅引用）

a = {"db": {"host": "h1", "port": 5432}, "debug": False}
# ↑ 基础配置
b = {"db": {"host": "h2"}, "debug": True}
# ↑ 覆盖配置：只改 db.host 和 debug
print(merge(a, b))              # {'db': {'host': 'h2', 'port': 5432}, 'debug': True}
# ↑ 深合并：db 里的 port 被保留，host 被覆盖
print(merge(a, b, deep=False))  # {'db': {'host': 'h2'}, 'debug': True}
# ↑ 浅合并：整个 db 被 b 的 db 替换，port 丢失
```

**注意**：这里的 `out[k] = v` 是浅引用，原字典的可变值仍会被共享。要完全隔离得 `deepcopy`。

### 题目 23：LRU 缓存（手写）

不依赖 `functools`，用 `dict` + 双向链表思路或利用 dict 有序性。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 23 思路——用 dict 的插入序模拟 LRU：访问就删了重插到末尾，超容删最左 ----
class LRUCache:
    """利用 dict 3.7+ 保证插入序：访问后移到末尾，超容量删最左"""
    # ↑ 文档字符串（≈ Javadoc），说明实现依据
    def __init__(self, capacity: int):
        # ↑ 容量上限
        self.capacity = capacity
        # ↑ 保存容量
        self.data: dict = {}
        # ↑ 底层字典；顺序：最左=最久未用，最右=最近使用

    def get(self, key):
        # ↑ 读取并刷新"最近使用"顺序
        if key not in self.data:
            # ↑ 不存在直接返回 None（也可以抛异常，按需求定）
            return None
        self.data[key] = self.data.pop(key)      # 重新插入到末尾
        # ↑ pop 先删除，再赋值即插入到字典末尾；≈ LinkedHashMap 的 accessOrder
        return self.data[key]
        # ↑ 返回取到的值

    def put(self, key, value):
        # ↑ 写入或更新
        if key in self.data:
            # ↑ 已存在先删，保证后面插入到末尾
            self.data.pop(key)
        self.data[key] = value
        # ↑ 插入/更新到末尾
        if len(self.data) > self.capacity:
            # ↑ 超出容量
            oldest = next(iter(self.data))
            # ↑ iter(dict) 按插入序产出键，next 取第一个 = 最久未用；≈ iterator().next()
            del self.data[oldest]
            # ↑ 淘汰最左


c = LRUCache(2)
# ↑ 容量为 2
c.put("a", 1); c.put("b", 2)
# ↑ 依次放入 a、b；顺序变为 [a, b]
c.get("a")               # a 变最近使用
# ↑ 访问 a ⇒ 删除再插入，顺序变为 [b, a]
c.put("c", 3)            # 淘汰 b
# ↑ 放入 c 后超容，删最左 b，顺序变为 [a, c]
print(list(c.data))      # ['a', 'c']
# ↑ 验证剩余键及顺序
```

**考点**：`next(iter(dict))` 取第一个键（最旧的）；`dict.pop` + 重新赋值实现"移到末尾"。

### 题目 24：asyncio 并发限流

给定 100 个任务，最多同时跑 10 个，收集全部结果。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 24 思路——Semaphore 限流 + gather 并发收集，并统计实际并发峰值 ----
import asyncio
# ↑ 事件循环与并发原语
import random
# ↑ 随机模拟耗时

async def task(i):
    # ↑ 单个任务：随机睡 0~0.1 秒后返回平方
    await asyncio.sleep(random.random() * 0.1)
    # ↑ 模拟 IO 等待；await 让出事件循环
    return i * i
    # ↑ 计算结果

async def run_all(n=100, limit=10):
    # ↑ 启动 n 个任务，最多 limit 个同时运行
    sem = asyncio.Semaphore(limit)
    # ↑ 信号量：最多发放 limit 个"许可"
    peak = {"now": 0, "max": 0}
    # ↑ 用 dict 记录当前并发数和历史峰值（闭包内可修改）

    async def guarded(i):
        # ↑ 被信号量保护的包装任务
        async with sem:
            # ↑ 获取许可；拿不到就在这里排队（不占用线程）
            peak["now"] += 1
            # ↑ 进入临界区，当前并发 +1
            peak["max"] = max(peak["max"], peak["now"])
            # ↑ 更新历史峰值
            try:
                return await task(i)
                # ↑ 执行真正的任务
            finally:
                peak["now"] -= 1
                # ↑ 无论成功失败都要释放计数

    results = await asyncio.gather(*(guarded(i) for i in range(n)))
    # ↑ 星号解包生成器：把 n 个协程展开成 gather 的位置参数；≈ allOf
    print(f"并发峰值 {peak['max']}（应 <= {limit}）")
    # ↑ 验证限流生效：峰值不会超过 limit
    return results
    # ↑ 按输入顺序返回所有结果

res = asyncio.run(run_all())
# ↑ 启动事件循环并跑完
print(len(res), res[:5])
# ↑ 输出结果数量与前 5 个，确认全部完成
```

**对照 Java**：`asyncio.Semaphore` ≈ `java.util.concurrent.Semaphore`，语义一致。

### 题目 25：日志解析器

解析 `2024-05-20 14:30:00 ERROR [order] 超时 30s`，输出结构化 dict 列表，并按级别统计。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 25 思路——命名分组正则解析日志行，groupdict 直接得到结构化字段 ----
import re
# ↑ 正则
from collections import Counter
# ↑ 按级别统计

PATTERN = re.compile(
    # ↑ 预编译正则，避免每行重复编译；≈ Pattern.compile
    r"^(?P<ts>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\s+"
    # ↑ (?P<名字>...) 是命名分组；^ 锚定行首；这里捕获时间戳
    r"(?P<level>[A-Z]+)\s+"
    # ↑ 捕获全大写级别（ERROR/INFO/WARN）
    r"\[(?P<module>[^\]]+)\]\s+"
    # ↑ 捕获方括号里的模块名；[^\]]+ 表示"非右括号的一串字符"
    r"(?P<msg>.+)$"
    # ↑ 捕获剩余全部内容作为消息；$ 锚定行尾
)

def parse(lines: list[str]) -> list[dict]:
    # ↑ 批量解析；返回结构化字典列表
    out = []
    # ↑ 结果累加器
    for line in lines:
        # ↑ 逐行处理
        m = PATTERN.match(line.strip())
        # ↑ strip 去掉首尾空白；match 从头匹配，不匹配返回 None
        if m:
            # ↑ 只收合法日志行，脏数据自动跳过
            out.append(m.groupdict())
            # ↑ groupdict 把命名分组变成 {"ts":..., "level":..., ...}
    return out

lines = [
    # ↑ 混合了合法日志和脏数据
    "2024-05-20 14:30:00 ERROR [order] 超时 30s",
    "2024-05-20 14:30:01 INFO [gateway] 请求进入",
    "不是日志行",
    "2024-05-20 14:30:02 WARN [order] 库存偏低",
]

rows = parse(lines)
# ↑ 解析结果
print(len(rows))                                  # 3
# ↑ 4 行里 1 行不合法，被跳过
print(Counter(r["level"] for r in rows))          # {'ERROR':1,'INFO':1,'WARN':1}
# ↑ 生成器表达式取 level 字段，Counter 统计各出现 1 次
print(rows[0]["msg"])                             # 超时 30s
# ↑ 取第一条的 msg 字段
```

### 题目 26：CSV → 聚合 → JSON

```python
import json
# ↑ 标准库 JSON
from collections import defaultdict
# ↑ 默认值字典，省去初始化判断
from pathlib import Path
# ↑ 面向对象路径与文件读写

def aggregate(csv_path: str, json_path: str) -> dict[str, float]:

        encoding="utf-8",
```

```python
    async with httpx.AsyncClient(timeout=timeout) as client:
        # ↑ 创建客户端并复用连接池；with 结束自动关闭
        for attempt in range(1, retries + 1):
            # ↑ 第 1..retries 次尝试
            try:
                r = await client.get(url)
                # ↑ 发起异步 GET
                r.raise_for_status()
                # ↑ 4xx/5xx 主动抛 HTTPStatusError；≈ RestTemplate 的默认错误处理
                return r.json()
                # ↑ 成功就解析 JSON 并返回，不再重试
            except (httpx.TimeoutException, httpx.HTTPError) as e:
                # ↑ 捕获超时与 HTTP 错误
                last = e
                if attempt < retries:
                    # ↑ 最后一次失败就不再等待
                    await asyncio.sleep(0.2 * 2 ** (attempt - 1))
                    # ↑ 指数退避：0.2、0.4、0.8...（加随机抖动可防雪崩）
    print(f"全部失败：{last}")
    # ↑ 所有尝试都失败，打印最后异常
    return fallback
    # ↑ 返回兜底值（≈ @Fallback）
```

**对照项目**：这就是 Java 侧 `ResilientAiService` 的 `@Retry + @Fallback` 的 Python 版。

</details>

### 题目 29：找出所有"卡住"的阻塞调用

给定一段 async 代码，找出其中会导致事件循环卡死的地方。

```python
# ---- 本段讲：题 29 前半——一段"看起来是异步、实际会卡死事件循环"的反面代码 ----
# 逐处标注 ①~④ 为阻塞调用，⑤ 是唯一正确的异步等待。
import time, requests, sqlite3, asyncio
# ↑ 这里全是同步库；requests / sqlite3 / time.sleep 都会阻塞当前线程

async def handler(order_id):
    # ↑ 虽然声明成 async，但函数体里几乎没有 await，事件循环会被占住
    time.sleep(0.5)                                    # ①
    # ↑ ① 同步睡眠：整个线程停 0.5 秒，其他协程全部无法执行
    r = requests.get("https://api/x")                  # ②
    # ↑ ② 同步 HTTP：网络等待期间事件循环同样被卡死
    conn = sqlite3.connect("db.sqlite")
    # ↑ 建立同步 SQLite 连接
    rows = conn.execute("SELECT * FROM t").fetchall()  # ③
    # ↑ ③ 同步查询：磁盘 IO 阻塞事件循环
    with open("log.txt", "a", encoding="utf-8") as f:
        # ↑ 同步文件 IO
        f.write("x")                                   # ④
        # ↑ ④ 写文件也是阻塞操作
    await asyncio.sleep(0.1)                           # ⑤
    # ↑ ⑤ 唯一正确：await 会让出事件循环，其他协程可继续跑
    return rows
    # ↑ 返回查询结果
```

<details>
<summary>参考答案</summary>

①②③④ 全部是同步阻塞，会卡死 loop（⑤ 是唯一正确的非阻塞等待）。

修法：

```python
# ---- 本段讲：题 29 后半——把每个阻塞点替换成"真异步"或丢进线程池 ----
import asyncio, sqlite3
# ↑ asyncio 提供 sleep/to_thread；sqlite3 仍用同步 API，但包进线程池

async def handler(order_id):
    # ↑ 改造后的异步处理器
    await asyncio.sleep(0.5)                                    # ① 延迟用 asyncio.sleep
    # ↑ ① 非阻塞延迟：让出事件循环

    import httpx
    # ↑ 换成支持 async 的 HTTP 客户端
    async with httpx.AsyncClient() as c:
        # ↑ 异步客户端，with 结束自动关闭连接
        r = await c.get("https://api/x")                        # ② 换异步客户端
        # ↑ ② await 期间事件循环可调度其他任务

    rows = await asyncio.to_thread(_query)                      # ③ 阻塞 DB 丢线程池
    # ↑ ③ 同步 DB 调用放到工作线程，主线程不被阻塞；≈ 专用线程池

    await asyncio.to_thread(_write_log, "x")                    # ④ 文件 IO 同理
    # ↑ ④ 同步文件写入也丢线程池
    await asyncio.sleep(0.1)
    # ↑ 普通异步等待
    return rows
    # ↑ 返回结果

def _query():
    # ↑ 同步查询函数：可安全地在工作线程执行
    conn = sqlite3.connect("db.sqlite")
    # ↑ 建连接（注意：连接不能跨线程共享，所以在线程内创建）
    try:
        return conn.execute("SELECT * FROM t").fetchall()
        # ↑ 执行查询并取全部行
    finally:
        conn.close()
        # ↑ 确保连接关闭（异常也会关）

def _write_log(s):
    # ↑ 同步写日志函数
    with open("log.txt", "a", encoding="utf-8") as f:
        # ↑ 追加模式打开，显式 UTF-8
        f.write(s)
        # ↑ 写入内容
```

**判断标准**：**任何不是 `await` 的 IO 调用都是 bug**。这是审查 async 代码时最该盯的一条。

</details>

### 题目 30：给 `ai-cs-py-chat` 加熔断

在 `LLMClient` 外面加熔断：连续 5 次失败后，30 秒内直接返回降级文案，不再请求。

<details>
<summary>参考答案</summary>

```python
# ---- 本段讲：题 30 思路——手写三态熔断器（CLOSED→OPEN→HALF_OPEN）+ 包装客户端 ----
import time
# ↑ 用 monotonic 计算经过时间（不受系统时钟回拨影响）
from collections.abc import AsyncIterator
# ↑ 流式方法的返回类型注解

class CircuitBreaker:
    # ↑ 熔断器状态机；≈ Resilience4j 的 CircuitBreaker
    CLOSED, OPEN, HALF_OPEN = "closed", "open", "half_open"
    # ↑ 类属性定义三个状态常量（元组解包赋值）

    def __init__(self, threshold=5, cooldown=30.0):
        # ↑ threshold=连续失败阈值；cooldown=熔断冷却秒数
        self.threshold = threshold
        self.cooldown = cooldown
        self.state = self.CLOSED
        # ↑ 初始为关闭（正常放行）
        self.failures = 0
        # ↑ 连续失败计数
        self.opened_at = 0.0
        # ↑ 进入 OPEN 的时间戳

    def allow(self) -> bool:
        # ↑ 每次请求前询问"是否放行"
        if self.state == self.CLOSED:
            # ↑ 正常状态：全部放行
            return True
        if self.state == self.OPEN:
            # ↑ 熔断中：只在冷却结束后试探一次
            if time.monotonic() - self.opened_at >= self.cooldown:
                # ↑ 冷却期满
                self.state = self.HALF_OPEN
                # ↑ 转半开：放一个探针请求
                return True
            return False
            # ↑ 冷却期未满：直接拒绝，不再请求下游
        return True                      # HALF_OPEN：放一个探针
        # ↑ 半开状态放行探针，由结果决定回到 CLOSED 还是重新 OPEN

    def on_success(self):
        # ↑ 探针/正常请求成功
        self.state = self.CLOSED
        # ↑ 恢复正常
        self.failures = 0
        # ↑ 清零失败计数

    def on_failure(self):
        # ↑ 请求失败
        self.failures += 1
        # ↑ 累计失败次数
        if self.state == self.HALF_OPEN or self.failures >= self.threshold:
            # ↑ 探针失败，或连续失败达阈值 ⇒ 熔断
            self.state = self.OPEN
            # ↑ 打开断路器
            self.opened_at = time.monotonic()
            # ↑ 记录打开时刻，用于计算冷却


class GuardedLLM:
    # ↑ 装饰器式包装：在不改原客户端的前提下加熔断
    def __init__(self, inner, breaker: CircuitBreaker | None = None, fallback="服务繁忙，请稍后重试"):
        # ↑ inner=被包装的真实客户端；breaker 可注入便于测试
        self.inner = inner
        self.breaker = breaker or CircuitBreaker()
        # ↑ 没传就新建一个
        self.fallback = fallback
        # ↑ 熔断时返回的兜底文案

    async def chat(self, history, message) -> str:
        # ↑ 非流式调用
        if not self.breaker.allow():
            # ↑ 被熔断 ⇒ 不再请求下游
            return self.fallback
            # ↑ 直接返回降级文案
        try:
            text = await self.inner.chat(history, message)
            # ↑ 真正调用
            self.breaker.on_success()
            # ↑ 成功则复位熔断器
            return text
        except Exception:
            # ↑ 任何异常都视为失败（生产可按异常类型细分）
            self.breaker.on_failure()
            # ↑ 失败计数 + 可能触发熔断
            return self.fallback
            # ↑ 返回降级文案，而不是把异常抛给调用方

    async def chat_stream(self, history, message) -> AsyncIterator[str]:
        # ↑ 流式调用：是异步生成器，所以降级也用 yield
        if not self.breaker.allow():
            # ↑ 熔断中
            yield self.fallback
            # ↑ 直接产出一段降级文本
            return
            # ↑ 结束生成器
        try:
            async for d in self.inner.chat_stream(history, message):
                # ↑ 逐块转发下游数据
                yield d
            self.breaker.on_success()
            # ↑ 整个流正常结束才算成功
        except Exception:
            # ↑ 中途异常
            self.breaker.on_failure()
            # ↑ 记一次失败
            yield self.fallback
            # ↑ 补一段降级文本，避免前端无响应
```

**对照项目**：这就是 Resilience4j `CircuitBreaker` 的最小实现。区别在于 Java 侧用注解 + AOP 自动织入，Python 侧显式包装——**Python 里横切关注点通常靠装饰器或包装类，没有 AOP 魔法**。

</details>
