# 雾山夜行记

夜雾漫上山脊
林深不见归路
少年提着灯笼
独自走进雾里
风从谷底吹来
吹熄了手中火
四周忽然安静
只听得到心跳
他摸黑向前走
脚下枯枝作响
远处传来钟声
一声接着一声
像是有人呼唤
又像是风吹过
他循着钟声走
雾渐渐淡了些
前方出现一座
残破的古寺庙
山门半掩半开
门上布满青苔
他轻轻推开门
尘埃扑面而来
殿内烛火摇曳
照着一尊石佛
佛前坐着老者
白发垂到腰间
老者睁开双眼
问他从何而来
少年说迷了路
想借一盏灯火
老者笑而不语
递给他一枚钱
说这不是灯火
却能照亮归途
少年低头看去
铜钱上刻着字
刻着来时的路
刻着去时的门
他忽然明白了
路本就在心中
抬头再问老者
老者已不见了
石佛依旧微笑
烛火依旧摇曳
他走出古寺门
雾已散了大半
天边泛起微光
山道清晰可见
他沿着山路走
脚步轻快许多
路过一片竹林
竹叶沙沙作响
像是老者笑声
又像是风在唱
走到半山腰时
遇见一个樵夫
樵夫问他去哪
他说要回家去
樵夫指了指路
说山下便是村
少年谢过樵夫
继续向下走去
路过一条小溪
溪水清澈见底
他蹲下洗了脸
水中映出朝霞
也映出他自己
不再是迷茫样
他起身继续走
村口老槐树下
母亲正在张望
看见他的身影
快步迎了上来
问他去了哪里
一夜都未归家
少年笑了笑说
去了趟雾山顶
母亲拍拍他肩
说回来就好啊
炊烟袅袅升起
村子渐渐醒了
鸡鸣犬吠相闻
新的一天开始
少年回头望去
雾山已经隐去
只在记忆深处
留下那盏灯火
他握紧那枚钱
走进自家院门
从此每当夜行
心中便有光亮
多年后他长大
也成了白发人
常在村口树下
给孩童讲故事
讲那座雾中山
讲那盏心中灯
孩子们听得痴
问他可是真的
他笑着不说话
从怀中掏出钱
铜钱已经磨亮
字迹依然清晰
刻着来时的路
刻着去时的门
孩童们传着看
眼里闪着光芒
他说路在脚下
灯在每个人心
只要心中有光
就不怕夜路长
夕阳慢慢西沉
染红了半边天
他拄着拐杖走
影子拉得很长
走回那座小院
点上檐下灯笼
灯火摇曳温暖
照亮一方天地
夜里他做了个梦
梦见回到雾山
老者坐在佛前
依旧白发垂腰
老者对他微笑
说你已找到灯
他在梦中行礼
醒来泪湿枕巾
窗外月色如水
洒在铜钱之上
他把它握在手
安安稳稳睡去
从此山高水长
灯火代代相传
